# kernel Emulation template

A simple emulation template for android kernels

- emu.sh: start script
- rootfs.cpio: generated by buildroot

## How to use

put `bzImage` or `kernel` in cwd.
edit `QEMU_DIR` to the path your qemu source code lives in.
run `./emu.sh`

export `QEMU_GDB_ARGS` to enable gdb debug session.
